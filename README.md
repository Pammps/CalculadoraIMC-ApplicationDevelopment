# Calculadora de IMC — React

Projeto desenvolvido a partir da calculadora apresentada na aula de Application Development.

## O que foi feito

- Finalização do cálculo do IMC com altura e peso.
- Conversão de valores com vírgula para o cálculo.
- Classificação do resultado usando a tabela de dados trabalhada em aula.
- Tela de resultado com IMC e situação atual.
- Tabela completa de classificações.
- Destaque visual da classificação encontrada.
- Validação dos campos e mensagem de erro.
- Botão para limpar os campos.
- Botão para calcular novamente.
- Possibilidade de calcular também pressionando Enter no formulário.
- Novo layout, com cores, espaçamentos, bordas e aparência responsiva.
- Componentização mantida com `Button`, `ImcCalc` e `ImcTable`.

## Como executar

```bash
npm install
npm run dev
```

Depois, abra o endereço mostrado pelo Vite no navegador.

## Build

```bash
npm run build
```
